QC traps: what gets a stump sent back

A low gate is not enough. These are the send-back causes from the audits and the War Room.

Values no upload holds

Ungrounded GTFA or rubric values. Every exact figure must trace to an uploaded file.

Inputs not uploaded

A file the item depends on is never attached, so a reviewer cannot verify the answer.

Unasked criteria

Criteria lifted from Not Known while explicit asks in the turn have no criterion.

Invalid run

A single turn that copies the opener, a drip-fed or steered chat, or an unrecorded steering turn.

Evidence not from this run

An output the run never produced, a previous run's PDF used as input, or a turn record edited after the run.

Grading claims instead of state

The Gmail card is a compose preview. Grade cards from the share page, never from the chat PDF placeholder.

Time-zone display artefacts

A demo account in IST, GMT+03 or US time is not an error by itself. Read the share page before failing it.

Gaming the gate

Cutting criteria, inverting weights or misgrading to get under 40%. Harden the item instead.

✅
A stump only counts if a careful agent would have passed. Same prompt, same inputs, same tools: the evidence was reachable, the request was clear, and nothing was hidden, broken or forced. If a careful agent would also have failed, it is not a valid stump. Harden the item; never game the gate.

Caveats: 53 hand-checked cases and 81 tagged tasks, 2 to 5 universes per locale. Tags are not exhaustive, so a task can list a technique it was not designed around. Images, email exports and calendar exports are thin (fewer than 5 tasks) and there are no audio tasks, so the selector flags low confidence. Rates are QC's corrected grading, not the contributors' originals.
